# CampusAtlas
## Smart Campus Facilities Management System

CampusAtlas is a Java application developed for the
Advanced Database Systems semester project at
Brno University of Technology.

### Project Features
- Interactive campus map
- Spatial data management using Oracle
- Spatial queries and analysis
- Multimedia storage and image search
- Campus facility management

### Technologies
- Java
- Oracle Database
- Java Swing
- Gradle
